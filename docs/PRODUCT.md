# MinkExcel documentation

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Explain why MinkExcel exists, how to install and use it, its public API,
its differences from ExcelJS, and its recorded performance results.

## Users

Inferred from the library and requested content: JavaScript and TypeScript
developers reading setup instructions, looking up methods, or evaluating XLSX tools.

## Capabilities and Constraints

Six static documentation pages published through GitHub Pages. Build without
site dependencies. Keep library source behavior and recorded benchmark truth.
Work on mobile first. All content and default measurements remain usable without JavaScript.

## Brand Commitments

User selected Vercel Geist styling, approved the Next.js documentation reference,
requested Solar icons and explicitly prioritized mobile layout. Preserve the MinkExcel logo.

## Evidence on Hand

src/model.ts and public exports; README.md and contributor instructions;
benchmarks/matrix.json and benchmarks/matrix-node.json; existing content.mjs.
Reference: https://nextjs.org/docs/app/getting-started/installation
